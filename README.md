## Selected Projects

### 1. Homeopathy E-commerce Platform

**Role:** Co-Founder & Software Architect  
**Status:** In development / pre-launch

A web-based commerce platform built to support the operations of a homeopathy business.

The project includes a customer-facing storefront, internal dashboard, backend API, and shared database infrastructure.

**Engineering highlights:**
- Full-stack application architecture using Next.js, React, TypeScript, and Node.js
- Shared data model across multiple applications
- Order and payment lifecycle management
- Transactional updates and reliable handling of payment events
- Authentication and role-based access control
- Deployment and maintenance on Linux servers

[Explore the project](./projects/homeopathy-platform/)

### 2. Homeopathy Repertory Search

A search-oriented application for navigating a large hierarchical collection of homeopathic rubrics.

The challenge is to make deeply nested information searchable and useful without losing the relationships between parent rubrics, sub-rubrics, and remedies.

**Engineering highlights:**
- Hierarchical data modeling
- Search across nested structures
- Database and query design
- User experience for navigating complex information

[Explore the project](./projects/repertory-search/)
